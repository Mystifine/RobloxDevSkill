# Using the scripts

## Loading into Studio

`python scripts/studio_mcp.py luau FILE` runs a file through Studio's own MCP server, with or without a Studio MCP tool; a first line `--@use RigSkin, RigAudit` inlines those scripts, keeping their source out of the conversation. Otherwise serve this folder (`python -m http.server 8394 --bind 127.0.0.1 --directory <skill>/scripts`; `python3` on macOS/Linux), then `loadstring(game:GetService("HttpService"):GetAsync(url, true))()`. A game's HTTP setting ships with it, so if it is off leave it off: pass the source to `loadstring`, or use a temporary ModuleScript (the only way on the client; one the Play server puts in ReplicatedStorage reaches the client; in Edit, one in CoreGui is never saved with the place). Delete what you add.

- **Loading:** the `.luau` files are plain Studio modules. Run them with `studio_mcp.py` (a `--@use` line inlines them through `loadstring`, Edit or server), load one through a local static server and `loadstring`, or use a temporary ModuleScript (client), as `SKILL.md` describes.
- **Where they run:**
  - `UIBounds`, `AssetAudit`, `ZFight`, `RigAudit`, `AnimationInspector` and `GameInventory` run in Edit.
  - `RigSkin` runs in Edit, or on a game's server to dress characters; `roblox_rig.py` and `skin_kit.py` run inside Blender (`import roblox_rig, skin_kit`; tested on 5.1).
  - `studio_mcp.py`, `upload_asset.py`, `clip_import.py` and `find_blender.py` run locally with Python 3 (standard library only), `ref_sheet.py` and `gif_preview.py` with Pillow; `studio_mcp.py` starts Studio's MCP server (`STUDIO_MCP`, or `mcp.bat` on Windows), and its `save` writes any instance as an upload-ready `.rbxm`.
  - `blender_anim.py` runs inside Blender 4.5+ (tested on 5.1), its pose checks also in plain Python; `r6_rig.py` fetches and copies locally, the rest inside Blender. `ClipImport` runs in Edit.
  - `VFXInspector` lints in Edit (`layer` breaks the ZOffset ties it finds) and photographs in Play (`references/art/vfx.md` section 8).
  - `ParticlePlayer` and `UIParity` run on the client (Play); prefer the project's own particle player.
  - `icon_outlines.py` runs locally: `uv run --with numpy --with pillow python icon_outlines.py <folder>`.
  - `learn.py` runs locally with Python 3 (standard library only).
  - `export_place.luau` runs in Lune: `lune run export_place.luau <place.rbxl> <out folder>`.
  - `PacingSim.luau` runs in Lune (or any Luau VM, Studio included): copy it beside a model, `lune run model.luau` (`references/design/game-economy.md`).
  - `scripts/codex/` runs locally with Node 20+ through `handoff.sh` (Git Bash on Windows), from Claude Code (`references/codex/handoff.md`).
