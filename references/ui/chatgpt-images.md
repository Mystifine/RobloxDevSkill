# UI: generating images through ChatGPT in Chrome

For icon sheets made through the user's own ChatGPT account in their Chrome (the browser extension's tools), beside [icons.md](icons.md), whose sheet layout, outline, transparency and upload rules apply. One run made nine 1536x1024 sheets in three conversations (icons, shop cards, portraits), sliced into 47 masters of 512 px.

- **Attach references through the hidden "Attach photos" file input, never the upload button:** `find` returns several hidden `file-input "Attach photos"` refs, and after a reply a second set appears (one "in Stop", one "in Start Voice"); the one in "Start Voice" is the live composer's. Uploading up to 5 PNGs at once there worked every time; clicking a button opens a native file picker the agent cannot use.
- **Tell that an image is finished by the composer's visible `Start Voice` button, not by counting images:** a preview `Generated image` at full natural size appears in the page long before the reply ends (while it still says "Refined the icon sheet" or "Inspecting transparency issues"), and a hidden `Stop` button lingers in the page, so counting images or looking for "Stop" gave false finishes and false busy states. The composer shows a visible `Start Voice` button only when idle. Replies took 1.5 to 2 minutes; a `javascript_tool` wait loop longer than about 40 s timed out the call ("Runtime.evaluate timed out after 45000ms"), so poll in short calls.
- **Download each image by fetching its blob in the page:** a generated image is an `img` with alt "Generated image N" and a `blob:https://chatgpt.com/...` src, a 1536x1024 PNG. In the page, `fetch(src).then(r => r.blob())`, then a click on an `<a download="name.png">` made from it, saved the full-size PNG (1.3 to 2.5 MB) to the user's Downloads folder every time (9 of 9), keeping the image out of the agent's context. The alt numbering restarts at 1 in each reply and older turns leave the page, so take the last generated image after each reply, and name each download so files never collide.
- **A reply can hold two candidates:** one asked "Which image do you like more?" with two full sheets; both were downloaded and the closer match kept, cell by cell.
- **Transparency comes back on about half the sheets** (the fix: [icons.md](icons.md), masters).
