# Stud relief and toy forms

Use only when the [visual-style dispatcher](../visual-style.md) selects these characteristics. Studs, example palettes and outlines are not universal requirements.

- Chunky silhouettes, faceted or beveled volumes, layered plates and exaggerated features where the reference shows them. Shape the anatomy instead of leaving a stack of blockout primitives.
- Small square/beveled studs follow the local surface orientation in regular rows. Use geometry where it changes the silhouette and mapped relief where visually equivalent; compare scale and spacing at game distance. A root Part's `TopSurface = Studs` does not create studs on a visible MeshPart.
- Broad, readable color blocks and restrained material variation. Match the supplied palette; simple plastic/stone shading is useful where appropriate. Add Neon or emissive accents and outlines only when selected by the design.

If Monster Pack is the actual reference, inspect `Workspace["Monstrer Pack"]` (also check the correctly spelled name) when available: Ossarok_Violet's broad plates, Gargouille's angular anatomy and Cerbere_Lave's accent channels illustrate this treatment. That pack uses black-outline Highlights with transparent fill; cyan selection borders are editor feedback. Other references need not share its navy/charcoal, gray/ivory and saturated-accent palette.

Materials and map selection: [modeling.md](../modeling.md#materials-and-textures).
